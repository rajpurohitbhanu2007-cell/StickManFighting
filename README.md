# ⚔️ STICK CLASH: STAT OVERLOAD (STANDALONE WINDOWS APP)

A retro-arcade fighting game built with Capcom CPS-2 physics (*Vampire Savior*, *Street Fighter Alpha 3*, and *Marvel vs. Capcom*), featuring a true **16:9 Desktop Application interface**, **Arco-style cinematic title screen**, **segmented stat-bar roster selection**, and **on-screen combat key legends**!

---

## 🚀 How to Launch as a Standalone Windows Desktop App

### 1-Click Launch (Recommended)
Simply **double-click** the file:
```
PlayStickClash.bat
```
*(Or in your terminal run: `python desktop_app.py`)*

This launches the game in a **dedicated, borderless native Windows application window** (no browser address bar, no browser tabs, 100% focused on your game).

### Direct Browser Play (Alternative)
You can still open [`index.html`](file:///c:/CodeDirectory/CODES/StickManFighting/index.html) directly in any web browser if preferred.

---

## 🖥️ Screen & Window Controls

* **Toggle Fullscreen:** Press <kbd>F</kbd> anytime or click the **⛶ FULLSCREEN [F]** button in the top-right corner.
* **Live Updating:** As we add new moves, characters, stages, and features, the desktop app dynamically loads the updated files immediately without needing to recompile!

## 🎮 Controls

### Movement (Leverless / Hitbox Standard)
* <kbd>A</kbd>: Move Left / Back
* <kbd>S</kbd>: **Down / Crouch** (Lowers hurtbox by 40% to duck under high attacks!)
* <kbd>D</kbd>: Move Right / Forward
* <kbd>SPACE</kbd>: **Up / Jump** (Thumb jump for fastest reaction time)

### Full-Size Keyboard (Numpad Layout) — Recommended
| Action | Key | Move Details |
| :--- | :---: | :--- |
| **Light Punch (LP)** | <kbd>Num 7</kbd> | Fast 3-frame jab poke |
| **Medium Punch (MP)** | <kbd>Num 8</kbd> | Straight body blow |
| **Heavy Punch (HP)** | <kbd>Num 9</kbd> | Overhead haymaker *(Meteor dive slam in mid-air)* |
| **Light Kick (LK)** | <kbd>Num 4</kbd> | Low shin kick poke |
| **Medium Kick (MK)** | <kbd>Num 5</kbd> | Step-in roundhouse |
| **Heavy Kick (HK)** | <kbd>Num 6</kbd> | **Launcher Backflip** *(Tap <kbd>SPACE</kbd> on hit to Super Jump!)* |
| **Throw** | <kbd>Left Shift</kbd> | Close-range unblockable throw |
| **Parry / V-Skill** | <kbd>Num +</kbd> | *Street Fighter III* parry freeze |
| **Drive Impact** | <kbd>Num 0</kbd> | *Street Fighter 6* armored smash *(absorbs 2 hits!)* |
| **3× Punch (Super)** | <kbd>Num 1</kbd> | Overdrive cinematic multi-slash barrage |
| **3× Kick (Dash)** | <kbd>Num 2</kbd> | Quick phase dash |
